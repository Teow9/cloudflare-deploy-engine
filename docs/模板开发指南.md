# 模板开发指南（templates 轴）

> 模板轴 = 预构建静态产物 + `template.json` 元数据（ADR-002：**只分发构建产物**，
> 源码放 `templates-src/` 仅供维护者；用户机器零 Node 依赖）。

## 一、目录约定

```
templates/<id>/
├── template.json          # 元数据（必填）
├── index.html ...         # 预构建产物（直接可部署）
└── ...                    # 任何静态文件；template.json 不参与部署
```

1. 在 `plugins.json` 的 `templates` 段注册：`{ "id": "<id>", "enabled": true, "path": "templates/<id>" }`。
2. 产物必须通过 `check-build-integrity.ps1`（见 §五）与 CI 门禁（templates 总尺寸 ≤ 3MB）。

## 二、template.json 规范

```json
{
  "id": "my-template",
  "name": "我的模板",
  "version": "1.0.0",
  "description": "一句话描述",
  "cloudflare": { "kv": false, "env": { "API_BASE": "https://example.com" } },
  "parameters": [
    { "name": "site_title", "label": "站点标题", "type": "string", "default": "我的站点" },
    { "name": "theme", "label": "主题色", "type": "string", "default": "dark" }
  ],
  "ai": { "keywords": ["博客", "个人网站"] }
}
```

| 字段 | 说明 |
| :--- | :--- |
| `cloudflare.kv` | 是否要求 KV 绑定（true 时引擎自动创建/复用并 PATCH 绑定） |
| `cloudflare.env` | 环境变量（部署时写入 production/preview 配置） |
| `parameters[]` | 占位符参数：`type` 支持 `string` 与 `enum`（enum 需提供 `enum` 数组，UI 渲染为下拉，如 react-vite 的 `theme`）；`default` 为默认值 |
| `ai.keywords` | AI 选模板的关键词（ai-bridge 注入 system prompt） |

## 三、占位符替换

文本文件（`.html .css .js .mjs .json .md .txt .xml .svg .yaml .yml .toml`）中的
`{{参数名}}` 会在部署展开阶段被替换；二进制文件（图片/字体等）原样拷贝。

```html
<h1>{{site_title}}</h1>
<p>{{site_tagline}}</p>
```

- 未在 template.json 声明的 `{{key}}` 不会被替换（保持原样输出）。
- 部署输出目录在引擎缓存 `data/cache/tpl-<id>-<时间戳>/`，不污染模板源。

## 四、AI 联动（可选）

`ai.keywords` 帮助 AI 从需求描述匹配模板；参数 `default` 会被注入 system prompt，
AI 未指定时回填默认值。回填永远可编辑、不自动部署。

## 五、完整性检查（check-build-integrity.ps1）

发布前必须通过（M3/M5 门禁），检查项：

1. `templates/<id>/template.json` 存在且可解析；
2. 无 `node_modules/`、无 `.env`（防依赖/密钥泄漏）；
3. 总尺寸 ≤ 3MB；
4. 每个模板至少 1 个文件。

## 六、模板源码管理（维护者）

源码与构建脚本放 `templates-src/<id>/`；构建产出拷贝到 `templates/<id>/` 后
**删除构建中间产物**再提交。示例（react-vite）：

```powershell
cd templates-src/react-vite
npm ci && powershell -File build.ps1      # 维护者机器才需要 Node
# 产物已同步到 ../../templates/react-vite/（含 assets/ 静态文件）
```

> 说明：`plain` / `astro-site` 为**手工维护的预构建**（无 `templates-src` 源码构建流程）；
> `react-vite` / `docs-site` / `nav-site` 由 `templates-src/` 构建产出。

新增模板后运行 `powershell -File scripts\dev\build-release.ps1` 复跑全部门禁。
