## F. 备注

- 本矩阵的 🟡 项集中在两类：**交互桌面点击**（D2–D4）与**干净虚拟机**（A9/E2/E4）。
  前者可让作者本人在桌面应用上过一遍；后者需一台无 Node 的 Windows 虚拟机（或未装 Node
  的备用机器），按《使用教程.md》从下载到部署计时。
- 断网实测（B3）受本开发沙箱网络限制，建议虚拟机断网演练：预期行为 = 引擎报可读网络错误，
  UI 显示 RESULT.error，不崩溃。
