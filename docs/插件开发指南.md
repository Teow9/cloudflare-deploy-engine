# 插件开发指南（四轴 handler 契约，ADR-007）

> 万物皆插件：**sources（代码来源）/ templates（部署模板）/ ai（AI 后端）/ targets（部署目标）**。
> 用户通过修改 `plugins.json` 注册或停用插件；开发者为任意轴新增插件。

## 1. 注册（plugins.json）

```json
{
  "sources":  [{ "id": "my-source", "enabled": true, "handler": "scripts/plugins/sources/source-my.ps1" }],
  "templates":[{ "id": "my-tpl",  "enabled": true, "path": "templates/my-tpl" }],
  "ai":       [{ "id": "my-ai",    "enabled": true, "handler": "scripts/plugins/ai/ai-my.ps1" }],
  "targets":  [{ "id": "my-target","enabled": true, "handler": "scripts/plugins/targets/target-my.ps1" }]
}
```

- `handler`：PowerShell 脚本路径（相对仓库根）
- `path`：模板目录（templates 轴专用，须含 `template.json`）

## 2. Handler 文件契约

- 文件位于 `scripts/plugins/<轴>/<id>.ps1`。
- 必须导出函数 `Invoke-<前缀><PascalId>`，前缀映射：`sources→Source, templates→Template, ai→Ai, targets→Target`（例：`Invoke-SourceMy`）。
- 函数唯一参数：`[hashtable]$PluginArgs`（**注意：不能用 `Args` 作参数名**——与自动变量 `$args` 冲突，Windows PowerShell 无法绑定）；返回值：哈希表（成为 RESULT 的一部分）。
- 可 `点源 scripts\utils.ps1` 获得 `Write-LogLine` / `Invoke-Curl` / `Write-Utf8File` 等工具。
- 错误：`throw`（引擎统一捕获并输出 ERROR）。

## 3. 各轴语义

| 轴 | 输入（PluginArgs 约定） | 返回约定 |
| :--- | :--- | :--- |
| sources | `Path`（local/zip）/ `Url`+`Ref`（github） | `@{ root = <待部署目录绝对路径>; source = <id> }` |
| templates | 无 Args（invoke = 元数据） | `template.json` 解析结果（由 template-manager 保证默认值合并） |
| ai | `BaseUrl`/`ApiKey`/`Model`/`SystemPrompt`/`UserPrompt` | `@{ content = <模型回复>; model = <实际模型> }` |
| targets | `ConfigPath`/`SourceRoot`/`Project`/`DryRun`/`KvRequired`/`EnvVars`/`Action(deploy\|delete)` | `@{ action; project; url; ... }` |

## 4. 规则（必须遵守）

1. **凭证永不写入日志与部署产物**（ADR-001）：使用 `ConvertTo-RedactedText` 兜底；CF 凭证一律经 `config-manager` 解密后在进程内使用。
2. AI 轴只生成方案，**永不自动执行部署**（ADR-004）。
3. 涉及网络一律走 `Invoke-Curl`（强制 `--noproxy "*"`）。
4. 模板产物必须是通过 `check-build-integrity.ps1` 的**预构建物**（ADR-002），不得要求用户端 Node.js。
5. 新增/修改插件后必须通过 `tests\plugin-manager.tests.ps1` 与 CI 五线。

## 5. 验证

```powershell
# 枚举四轴
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\plugin-manager.ps1
# 调用某插件
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\plugin-manager.ps1 -Axis sources -Id local -ArgsJson '{"Path":"C:\\site"}'
```
