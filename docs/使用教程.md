# Cloudflare Deploy Engine 使用教程

> 目标：**全新 Windows 10/11 机器，从下载到部署成功 ≤ 15 分钟**，全程不需要安装 Node.js、
> git、wrangler 或任何其它软件（"零依赖"承诺，见 README）。

## 一、安装

1. 下载 `Cloudflare-Deploy-Engine-vX.Y.Z.zip`（Release 页）。
2. 解压到任意目录（建议英文路径，如 `D:\cde`）。
3. 首次运行 `cloudflare-deploy-engine-win_x64.exe`。
   - 若出现 SmartScreen 提示（未签名程序），点击 **更多信息 → 仍要运行**（ADR-005）。
   - 可在下载页核对 `SHA256.txt` 中的哈希与官方一致。

> 运行时基线：Windows 10/11（含 PowerShell 5.1 与 curl/tar，系统自带）；WebView2 运行时
> 缺失时按界面提示安装（一次性引导，不算"依赖软件"）。

## 二、首次启动

1. 首启弹出**免责声明与使用条款**，阅读后点击"我已阅读并同意"。
2. 打开 **🔒 Token 权限指引**，按指引创建 API Token：
   - Cloudflare Dashboard → My Profile → API Tokens → Create Token
   - 只勾选 **Cloudflare Pages — Edit**（本工具只做静态站直传，无需其它权限）；
   - 建议选择你的账号资源范围，不用账户全局密钥。
3. 回到主界面填写：**Account ID**（Dashboard 首页右侧可复制）、**邮箱**、**API Token**。
4. 点击 **💾 加密保存** —— 凭证经 Windows DPAPI 加密写入 `data/config.enc.json`，
   仅本机当前用户可解。

## 三、部署一个站点（3 种方式）

### 方式 A：内置模板（最快上手）

1. 部署区保持"内置模板"模式，选择模板（当前内置 5 个）：
   - `plain` 纯静态示例（零构建）；
   - `astro-site` Astro 博客站（预构建产物，用户零 Node 依赖）；
   - `react-vite` React 落地页（含 `theme` 下拉枚举参数：light/dark）；
   - `docs-site` 多页文档站（首页 / 指南 / API）；
   - `nav-site` 导航站（粘贴 JSON 链接数组生成卡片导航）。
2. 按需修改参数（站点标题等），可留空用默认值。
3. 项目名留空 → 自动派生（如模板 `plain` → 项目 `plain`）；也可自填
   （小写字母数字连字符，决定 `<项目名>.pages.dev` 域名）。
4. 点击 **🚀 部署**，右侧日志实时滚动；完成后结果区显示：

   | 字段 | 含义 |
   | :--- | :--- |
   | 站点 URL | `https://<项目>.pages.dev`（点击打开） |
   | 探针验收 ✅ | 引擎已实测边缘返回 2xx/3xx，站点真的活了 |
   | 部署尝试 | 平台故障窗口下自动重试次数 |
   | 后端 | native（引擎直传）或 wrangler（官方客户端） |

   建议先点 **演练 DryRun** 验证配置，全程不触碰云端。

### 方式 B：自定义来源（4 类）

切换到"自定义来源"：

- **📁 本地文件夹**：选择 `Path`（可直接"浏览…"），部署该文件夹下全部文件。
- **🐙 GitHub 仓库**：填 `owner/repo` 或完整 URL，可选分支/标签
  （默认 `main`）。引擎走 codeload zip + tar 解压，**不依赖 git/Node**。
- **🦊 GitLab 仓库**：填 `group/project`（支持多级）或完整 URL，可选 ref。
  引擎走 GitLab archive zip + tar 解压，零依赖。
- **📦 本地压缩包**：选择 zip/tar/tgz 文件，自动解压部署。

> 支持的文件名规则：路径不含空格与引号（引擎有显式校验并报可读错误）。

### 方式 C：AI 智能部署（只回填，永不自动执行）

1. 点击 **⚙ AI 设置**，填写 BaseUrl / 模型 / API Key（OpenAI 兼容协议，
   兼容 OpenAI、DeepSeek、Ollama、vLLM 等；Key 加密存储）。
2. 在输入框描述需求，如"我想做一个个人博客，标题叫我的小站"。
3. 点击 **✨ 生成方案并回填** —— AI 返回模板建议 + 参数并**自动回填表单**，
   全部可手动修改；部署仍由你自己点按钮触发（方案与执行解耦）。

## 四、日常操作

| 操作 | 入口 | 说明 |
| :--- | :--- | :--- |
| 再次部署 | 🚀 部署 | 复用上次项目（配置记忆 `pagesProject`），增量上传新资产 |
| 更换后端 | 部署后端下拉 | native 默认零依赖；wrangler 需自行安装（含 wrangler 的环境可用官方客户端，对平台故障更稳） |
| 取消任务 | 顶栏 ■ 取消 | 立即终止 PowerShell 子进程（25 分钟无结果自动终止） |
| 销毁项目 | 🗑 销毁项目 | 二次确认后删除整个 Pages 项目（站点下线） |
| 换机迁移 | 📤 导出 / 📥 导入 | 导出 = 口令加密文件（PBKDF2+AES-256）；导入 = 目标机重新 DPAPI 加密（ADR-003） |
| 清除配置 | 清除 | 删除本地全部配置（凭证 + AI + 项目记忆） |
| 卸载 | 删除文件夹 | 引擎不写注册表、不写 APPDATA，删除即完全卸载 |

## 五、常见问题

**Q：删除文件夹 = 完全卸载吗？**
A：是（ADR-008 口径）。应用自身零残留：凭证/日志/缓存全在应用目录内，不写注册表与
APPDATA。唯一例外：直接双击 exe 时，WebView2 运行时会在
`%APPDATA%\<exe名>\EBWebView` 写入**系统组件缓存**（Chromium 标准行为，与浏览器缓存同级，
由系统托管清理）。想要系统级零残留，用随包附带的 **`start-zeroresidue.cmd`** 启动即可
（缓存被收进应用目录 `data/webview2`，删文件夹即全清）。

**Q：部署 API 成功但站点 500？**
A：Cloudflare Pages 资产服务存在间歇性故障窗口（见《测试报告》）。引擎已内置韧性：
非 JSON 响应防护 + 自动重试 3 次（第 2 次起强制重传）+ 探针验收门 + `servingOk` 明示。
仍失败时：稍后重试，或切换 wrangler 后端（平台官方客户端路径）。

**Q：SmartScreen 拦截？**
A：未签名 exe 的正常提示（ADR-005）。点"更多信息 → 仍要运行"，并核对官方 SHA256。

**Q：Token 需要哪些权限？**
A：仅 **Cloudflare Pages:Edit**（见顶部指引）。不要用账户全局密钥；泄露即注销重建。

**Q：部署产物里会有我的 Token 吗？**
A：不会。ADR-001：默认不注入任何凭证进部署产物；CI 与测试均有零凭证断言。

**Q：AI 回填错了怎么办？**
A：所有回填都可编辑；AI 调用失败或 Key 无效时手动流程完全不受影响（降级路径）。
